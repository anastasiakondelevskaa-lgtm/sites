Ключи приложения Telegram

Задаются один раз. Возьмите их на my.telegram.org → API development tools, войдя под тем номером, которым будете парсить. Ключи личные: они видны только вам и хранятся на сервере в зашифрованном виде. Коллега вводит свои.

Где взять api_id и api_hash — по шагам
  1. Откройте my.telegram.org и введите номер того аккаунта, которым будете парсить — в международном виде, например +380671234567.
  2. Код придёт в само приложение Telegram, а не смс. Найдите его в чате «Telegram» и введите на сайте.
  3. Выберите пункт API development tools.
  4. Заполните форму. Обязательны только два поля: App title — любое название, например parser; Short name — латиницей, от 5 до 32 символов. Платформу можно оставить Other, описание — пустым.
  5. Нажмите Create application.
  6. На открывшейся странице возьмите App api_id (число) и App api_hash (32 символа) и впишите их в форму выше.
Приложение создаётся один раз на аккаунт: если вы уже создавали его раньше, формы не будет — значения просто показаны на странице. api_hash — это ключ, равный доступу приложения к аккаунту: не пересылайте его в переписке и не публикуйте. Если он утёк — заведите ключи под другим аккаунтом.
